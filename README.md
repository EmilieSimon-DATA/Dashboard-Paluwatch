# Projet Final Data Analyst- PALUWATCH
## Objectif
Analyser l’évolution du paludisme dans cinq pays d’Asie du Sud-Est (2015–2024), évaluer les progrès réalisés au regard des objectifs de l’OMS à horizon 2030 et développer un indicateur synthétique : le score PaluWatch.
